\# CETERO-S



Draft manuscript for future JOSS submission.



CETERO-S is a semiautomatic Python tool for the analysis of J–R resistance curves from compact tension C(T) fracture tests using the unloading compliance method.



The software combines automated numerical procedures with supervised user interaction, enabling traceable and auditable workflows instead of black-box processing.
